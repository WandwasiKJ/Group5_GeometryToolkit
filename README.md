# Group 5 Geometry Toolkit

A Python geometry toolkit demonstrating classes and objects through a `Rectangle` class.

## Features

- Validate positive rectangle dimensions.
- Calculate area and perimeter.
- Identify squares.
- Scale rectangle dimensions.
- Compare the areas of two rectangles.
- Print a readable rectangle description.

## Requirements

- Python 3.8 or newer

## Run the demonstration

From this folder, run:

```powershell
python "G 5.py"
```

The program creates sample rectangles, demonstrates the available operations, and shows how invalid scaling factors are rejected.

## Project Structure

- `G 5.py` - Rectangle class and demonstration program
